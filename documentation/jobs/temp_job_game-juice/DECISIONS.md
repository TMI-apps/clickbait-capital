# Decisions — game-juice

| #   | Decision                                                                                                                                                                                                                                                                                                                                           | Why                                                                                                                              |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| D1  | Juice is derived from the `BoardView` (last feed entry type + meter deltas, key = feed length); no change to `useGameSession` or the engine.                                                                                                                                                                                                       | The view already carries everything; sounds fire on the same render, so visuals and audio stay in sync without a second channel. |
| D2  | CSS keyframes (transform/opacity) for particles, flashes and entrances; Web Animations API only for the board shake and `requestAnimationFrame` for count-up text. No animation library.                                                                                                                                                           | Constraint from the orchestrator; compositor-only properties keep 60 fps.                                                        |
| D3  | `useMotionPreference` (game-juice) is the single in-app motion source; today it reads `prefers-reduced-motion`. The settings lap backs it with its toggle. Reduced: no particles, no shake, instant numbers; accents, deltas and MAX marks still show.                                                                                             | One seam for the settings lap; state change never depends on motion.                                                             |
| D4  | Particle caps: viral 12 emoji, ad 10 coins, news/event 0; win 14, loss 0.                                                                                                                                                                                                                                                                          | Mid-phone budget; news stays intentionally dull (design § 5).                                                                    |
| D5  | Wasted gains: the card shows the applied part (`min(delta, 100 − meter)`) plus a "MAX" mark when part is wasted (game-board D10: the number shown is the number applied); meters at 100 show a cap glow and a "MAX" label. Screen readers hear "verspild boven het maximum". The badge is the kit `CapBadge`, shared by card rows and full meters. | Teaches adapting without hiding the card's effect; colour is never the only signal.                                              |
| D6  | Viral flames sit on the Gebruikers meter (the design's "engagement-teller"); ad gold glow on Inkomsten; news shield on Reputatie.                                                                                                                                                                                                                  | The board's engagement counter is the users meter.                                                                               |
| D7  | End entrance lives in game-juice (`EndJuice` wrapper used by `GameBoard`); game-flow screens stay unchanged.                                                                                                                                                                                                                                       | Keeps game-flow out of the lap's edges.                                                                                          |
| D8  | News feedback: only the shield; no gain/loss flash and no count-up (numbers snap). Viral, ad and events flash and count.                                                                                                                                                                                                                           | Design § 5 "geen animatie / intentioneel saai" (loop-check finding).                                                             |
